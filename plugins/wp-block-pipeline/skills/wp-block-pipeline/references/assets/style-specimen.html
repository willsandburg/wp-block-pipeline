Body copy

This is a default paragraph at the medium size, which is the site's reading size. The column is capped at the content width so a line stays in the comfortable range, because a line that runs the full width of a desktop screen is tiring to read and people stop. It contains bold text, italic text and a link in running copy, so all three can be judged against the surrounding text rather than in isolation.

This is a lead paragraph at the large size. Use it once, directly under a heading, to carry the sentence that matters. Using it everywhere removes the emphasis it exists to create.

This is supporting copy in the secondary colour. It should sit back from the main text without becoming hard to read — it still has to clear 4.5:1 against the background behind it.

This is the small size, for captions, disclaimers and metadata.

A centred paragraph, for the rare case where centring is deliberate.

A full-bleed accent panel

A full-width section reads as wide only because the section before it was at the content width. If everything is full-bleed, nothing is.

The dark panel

Reversed text on the dark background. Check this carefully: a colour pairing that passes on the light canvas can fail here, and a button that reads well on light can disappear.

Small text on the dark panel is where reversed contrast usually fails first.

Links need checking here separately, because a link colour that reads well on the light canvas can be invisible on the dark one — and the site footer is usually the first place that shows.
